# Blender Color Grid Add-on

## Description
Un add-on Blender qui permet de créer une grille de couleurs et de la exporter dans la scène 3D sous forme de planes colorés.

## Fonctionnalités
- Configuration du nombre de colonnes et lignes
- Color picker pour chaque coin de la grille (4 coins)
- Création automatique d'une collection "tiles"
- Génération de planes avec les couleurs sélectionnées
- Espacement uniforme entre les éléments
- Interpolation des couleurs entre les coins

## Utilisation
1. Ouvrez le panneau dans la 3D Viewport (onglet "Color Grid")
2. Définissez le nombre de colonnes et lignes
3. Choisissez vos couleurs dans la grille
4. Cliquez sur "Generate Grid" pour créer les planes
